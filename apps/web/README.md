# MedGuard web

Next.js (App Router) frontend. See the [root README](../../README.md) for what the product does and how to run it, and
[docs/development.md](../../docs/development.md) for the test commands (`pnpm lint`, `pnpm test`, `pnpm build`).

The UI follows the MedGuard design system (colour tokens in `app/globals.css`, status chips that always pair a word, a shape and a
colour). All data comes from the API; there are no mock numbers.
